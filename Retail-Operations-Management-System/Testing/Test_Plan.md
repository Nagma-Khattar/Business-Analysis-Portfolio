# Test Plan

## Retail Operations Management System (ROMS)

**Client:** NorthStar Retail Inc.  
**Document Type:** Test Plan  
**Prepared By:** Nagma Khattar

---

# 1. Introduction

This Test Plan defines the testing strategy, objectives, scope, resources, and activities required to verify that the Retail Operations Management System (ROMS) satisfies its business and functional requirements.

---

# 2. Test Objectives

The objectives of testing are to:

- Verify that all functional requirements are implemented correctly.
- Ensure the application performs as expected under normal operating conditions.
- Validate business workflows.
- Identify and resolve defects before deployment.

---

# 3. Scope

### In Scope

- User Login
- Inventory Management
- Sales Transactions
- Customer Management
- Reporting

### Out of Scope

- Third-party payment gateway integration
- Mobile application
- Performance and load testing

---

# 4. Test Types

- Functional Testing
- Integration Testing
- System Testing
- User Acceptance Testing (UAT)
- Regression Testing

---

# 5. Test Environment

- Web Browser (Chrome, Edge)
- Windows 11
- REST API
- PostgreSQL Database

---

# 6. Entry Criteria

- Requirements approved
- Development completed
- Test environment available

---

# 7. Exit Criteria

- All critical defects resolved
- UAT completed successfully
- Business approval received

---

# 8. Roles and Responsibilities

| Role | Responsibility |
|------|----------------|
| Business Analyst | Review requirements and support UAT |
| Developer | Fix identified defects |
| Tester | Execute test cases |
| Store Manager | Perform User Acceptance Testing |

---

# 9. Risks

- Requirement changes
- Limited testing time
- Incomplete test data

---

# 10. Deliverables

- Test Plan
- Test Cases
- Defect Log
- Test Summary Report

---

# 11. Conclusion

This Test Plan provides the overall testing strategy to ensure that ROMS meets business requirements and delivers reliable functionality before deployment.
