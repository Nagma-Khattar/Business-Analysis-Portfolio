# User Acceptance Test (UAT) Test Cases

## Retail Operations Management System (ROMS)

**Client:** NorthStar Retail Inc.  
**Document Type:** User Acceptance Test Cases  
**Prepared By:** Nagma Khattar

---

# Purpose

This document defines the User Acceptance Test (UAT) cases to validate that the Retail Operations Management System (ROMS) satisfies business requirements and is ready for deployment.

---

| Test Case ID | Requirement | Test Scenario | Expected Result | Status |
|--------------|-------------|---------------|-----------------|--------|
| UAT-001 | User Login | Login with valid credentials | User is successfully logged in and redirected to the dashboard | Pass |
| UAT-002 | Add New Product | Add a new product with valid information | Product is successfully added to inventory | Pass |
| UAT-003 | View Inventory | Search and view inventory | Matching inventory records are displayed | Pass |
| UAT-004 | Update Inventory | Update product stock quantity | Inventory is updated successfully | Pass |
| UAT-005 | Record Sales Transaction | Complete a sales transaction | Sale is recorded and inventory is updated | Pass |
| UAT-006 | Create Customer Profile | Create a new customer profile | Customer profile is successfully created | Pass |
| UAT-007 | View Sales Report | Generate sales report | Sales report is displayed accurately | Pass |
| UAT-008 | Generate Business Reports | Generate business report | Business report is successfully generated | Pass |
| UAT-009 | Role-Based Access Control | Assign a role to a user and verify access permissions | User is granted access only to authorized features, unauthorized access is denied, and role changes are saved successfully | Pass |
